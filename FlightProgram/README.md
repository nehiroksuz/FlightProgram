# FlightProgram

## About

A simple C++ program for recording and analyzing simulated flight  data.
This project was created to practice C++ concepts and apply them in a simple flight data application.

### Features

- Records flight measurements
- Calculates maximum altitude
- Calculates average temperature

## C++ Concepts Practiced
- Classes
- Encapsulation
- Constructors
- Getters
- `std::vector`
- `const`

## Future Improvements
